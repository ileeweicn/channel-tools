channel-tools

channel-tools is a private, single-user tool that the owner of a small group of YouTube channels uses to manage their own channels.

It uses the YouTube Data API and the YouTube Analytics API to:

  • read performance data (views, watch time, retention, traffic sources) for the owner's own channels, to review how videos are doing;
  • update the owner's own videos: titles, descriptions, thumbnails, playlists.

It is not offered to the public and does not access anyone else's account.
